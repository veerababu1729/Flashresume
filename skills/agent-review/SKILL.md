# Autonomous Multi-Agent Review Skill (`/agent-review`)

## System Capability Overview (Pipeline Topology v4.0)
This skill defines a first-class system capability for autonomous, deterministic, hybrid AST-LLM code analysis. Upon invocation, it initializes the Multi-Agent Review Framework located in `backend/review/`.

The engine has shifted from a static, read-only analyzer to a self-correcting engine featuring bounded-execution topologies, adversarial multi-agent debate, and closed-loop telemetry.

## 9-Step DAG Execution Workflow

When this skill is invoked, the Orchestrator executes strictly in the following topological order:

1. **Incremental Ingestion & Boundary Computation (B)**: 
   - Replaces global context reading with Transitive Closure bounds:
     `B = Delta_diff U Callers(Delta_diff) U DataFlow(Delta_diff) U Interfaces(Delta_diff)`
   - Computes programmatic source-to-sink taint tracking paths (P_taint) via AST parsing.
2. **Context Routing**: Domain-specific projections of the execution boundary are injected via the `ICapabilityPlugin` SDK. (e.g., Security receives P_taint, Performance receives Loop Topologies).
3. **SDK-Bound Parallel Execution**: Auto-discover and trigger all 8 capability review agents bounded strictly by their isolated subgraphs.
4. **Semantic Validation & Deterministic Sandbox Gate (V)**: 
   - Candidate patch diffs undergo isolated containerized validation:
     * Syntax/AST compilation checks.
     * Static Linting validations.
     * Dynamic Test Matrix verification against `Tests(C_scope)`.
5. **Adversarial Debate Protocol**: 
   - For high-severity candidate findings, a Mediator Agent evaluates structural counter-evidence generated by an Adversary Agent. Findings are dropped if structurally disproven.
6. **Cross-Agent Evidence Resolution & Priority Amplification**: 
   - Correlates micro-findings along the Data Flow Graph into Vulnerability Chains (V_c).
   - Mutates priority dynamically based on chain multipliers.
7. **Root Cause Clustering (K-Reduction)**: 
   - Collapses localized, symptomatic findings into singular architectural root-cause matrices (F).
8. **Dynamic Priority Scoring & Policy Enforcement**: 
   - Shifts to an ROI-based debt model factoring in Fix-Cost Modifiers.
   - Applies hierarchical Policy Masks to mute findings prior to triage.
9. **Telemetry Export & Report Synthesis**: 
   - Exports the Telemetry Vector (T) containing FPR for closed-loop learning. If FPR > 0.20, rule strictness dynamically decays.
   - Outputs the Merge-Ready Diff and final validated Compliance Report.

## Invocation Protocol

### Programmatic CLI Execution:
Run the CLI entry point from the terminal:
```bash
python -m review.cli --mode Standard
```
or with custom targets:
```bash
python -m review.cli --mode Production --format sarif --output backend/reports/review_latest.json
```
